# GSC Fetch – landing page + demo

Static landing page for GSC Fetch (automated monthly Google Search Console reports and SEO audits in Google Sheets),
served with GitHub Pages.

- `index.html` – landing page
- `demo/` – click-through demo of sign-in, checkout (test mode, fictional payment) and the app.
  Data is stored only in the visitor's browser (localStorage).

Settings are in `CONFIG` at the bottom of `index.html` (brand name, app URL, demo mode, founder offer).
